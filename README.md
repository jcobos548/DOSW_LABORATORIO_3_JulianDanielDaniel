¿Qué es un pull request en GitHub?

Un Pull Request (PR) es una solicitud para integrar los cambios realizados en una rama de un repositorio con otra, normalmente hacia main. Permite revisar el código, comentar cambios, detectar errores y aprobar la integración antes de hacer el merge.

¿Cómo se crea un pull request en GitHub?

Subir los cambios a una rama del repositorio.
En GitHub, entrar al repositorio y seleccionar “Compare & pull request”.
Elegir la rama de origen y la rama destino, por ejemplo feature → main.
Escribir un título y explicar brevemente los cambios.
Seleccionar “Create pull request”.

¿Cómo se aprueba un pull request en GitHub?

Una persona con permisos de revisión entra al PR, analiza los cambios en “Files changed”, deja comentarios si es necesario y, si todo está correcto, selecciona “Approve” en la sección de revisión. Después, si se cumplen las reglas del repositorio, el PR puede integrarse mediante “Merge pull request”.
